# 収束モード

目的は**比較表を作ること**ではなく、**1つ選んで前に進むこと**。

## モード契約（破ったら収束になっていない）

1. **基準を先に決める。** 案を眺めてから基準を作らない。後付けの基準は結論の正当化にしかならない。
2. **必ず1つ選ぶ。** 「ケースバイケース」「どちらも良い」「状況によります」は禁止。情報が足りないなら「情報が足りないので、まず◯◯を確かめる」を決定として出す。
3. **捨てるものを言語化する。** トレードオフを書かない収束は、ただの結論の押し付け。
4. **撤回条件を書く。** 何が起きたらこの決定を見直すのかを明示する。

## 手順

### 0. 決定の種類を判定する
- **可逆（あとで戻せる）** → 分析は最小限。速さが価値。基準2つ、表なしで即決してよい。
- **不可逆（戻すコストが大きい）** → 以下をフルで回す。

判定を最初の1行に書く。ここを間違えると、軽い決定に重い分析をかけて時間を溶かす。

### 1. 基準を決める（案を見る前に）
2種類に分けて書く。

- **足切り要件（Must）**: 満たさなければ即除外。Yes/No で判定できる形にする。
- **評価軸（Want）**: 3〜5個。それぞれに重み（1〜3）をつける。

> 評価軸が案の数より多いなら、軸を減らす。分析麻痺のサイン。

### 2. 足切り
Must を満たさない案を落とす。**落とした理由を1行ずつ**残す（あとで復活させる可能性があるため）。

### 3. 採点
生き残った案を軸ごとに5点満点で採点し、重み付き合計を出す。表にする。

| 案 | 軸A(×3) | 軸B(×2) | 軸C(×1) | 合計 |
|---|---|---|---|---|

点数は議論の道具であって答えではない。**合計1位と直感が食い違うなら、軸か重みが間違っている**。その場で直して再計算する（結論を歪めるのではなく、基準を直す）。

### 4. 決定を書く
以下を全部埋めて初めて完了:

- **決定**: 選んだ案（1つ）
- **決め手**: 効いた軸を1〜2個
- **次点と、選ばなかった理由**: 1行
- **捨てるもの**: この決定で失う価値を具体的に。「特にない」は書かない（必ず何かある）
- **撤回条件**: 「◯◯が起きたら見直す」を1〜2個。観測可能な事象で書く
- **最初の一歩**: 24時間以内に着手できる具体行動を1つ

## 出力形式

```
決定の種類: 可逆 / 不可逆

## 基準
Must: ...
Want: 軸A(重み3) ... / 軸B(重み2) ... / 軸C(重み1) ...

## 足切り
- 案X: 除外（理由）

## 採点
（表）

## 決定
選択: ...
決め手: ...
次点: ...（選ばなかった理由）
捨てるもの: ...
撤回条件: ...
最初の一歩: ...
```

## アンチパターン

- 全案を平等に褒めて終わる
- 点数を後から辻褄合わせする（基準ではなく結論をいじっている）
- 「さらなる検討が必要です」で終わる → それは決定ではない
- 撤回条件が「うまくいかなかったら」→ 観測不能。何をもって「うまくいかない」とするかを書く
- 可逆な決定に重い比較表を作る → 種類判定を飛ばしている
