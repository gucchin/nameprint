# 遅延提出の減点基準 (Late-Submission Penalty Policy)

数値計算法2026の課題採点で使う、段階的減点方式の標準ポリシー。第8回課題(L8)で
ユーザーが明示的に選択・承認した方式であり、以降の全講義回でこれを既定値として使う。
特別な事情がない限り、講義回ごとに再確認・再提案する必要はない。

| 区分 | 減点 | 提出点(満点50点中) | 備考 |
|---|---|---|---|
| 期限内 | ±0点 | 50点 | |
| 締切から24時間以内 | -5点 | 45点 | |
| 締切から24時間〜3日 | -10点 | 40点 | |
| 締切から3日〜7日 | -20点 | 30点 | |
| 締切から7日超 | -35点 | 15点 | **要相談** — 一律減点ではなく、教員に直接確認することを推奨する旨をコメントに残す |

## 遅延の判定方法

Moodleの成績CSVの「ステータス」列に、"N日N時間遅く提出" のような文字列が入っていることが多い。
そこから遅延時間を読み取り、上表のどの区分に該当するか判定する。ステータス列に情報がない場合は、
提出ファイルのタイムスタンプや「最終更新日時(提出)」列と課題の締切日時を比較して判定する。

締切日時そのものは課題PDFやMoodle上のシラバス情報から確認すること(推測しない)。

## compute_grades.py での使い方

`scripts/compute_grades.py` に渡す `grading_input.json` の各学生エントリで、該当する区分の
キー文字列(例: `"24時間以内"`)を `late_label` に設定する。期限内なら `null` または省略でよい。
上表と異なる区分を使いたい特殊なケースがあれば、`late_penalty_tiers` フィールドで丸ごと
上書きできる(スクリプトのdocstring参照)。
